Encrypted seed-only recovery

Create a second private backup for the same DID. It contains only the Ed25519 seed encrypted under a separate passphrase—not public records, contributions, or room history.

Do not copy the seed into a chat or support ticket. The keygen output contains your private key. Anyone with the seed can permanently impersonate this DID.

The raw seed is never displayed, copied, logged, placed in a URL, or sent to the publication proxy.
