Run the studio.

Keep the keys yours.

The DID website and Technocore Chat server are separate. You can host either one, both, or use the public Technocore server with a locally served studio.

Identity warning: never enter a wallet seed phrase, exchange key, or private key used by another service. A Technocore DID is an independent Ed25519 identity and does not guarantee any reward.

1. DID Studio website

Install Git and Node.js 20 or newer. These commands are identical on Windows PowerShell/Command Prompt, macOS Terminal, and Linux:

git clone YOUR_REPOSITORY_URL technocore-did-studio
cd technocore-did-studio
npm install
npm test
npm run build
npm run serve

Open http://localhost:4173. The production-ready static output is in dist/; upload that folder to any HTTPS static host.

Move one identity to another machine

  1. Generate the identity on machine A and save the encrypted JSON backup.
  2. Move the encrypted backup through a trusted channel.
  3. Keep or transfer its passphrase separately.
  4. Restore on machine B and compare the complete public DID.

The clear key remains in memory only. The studio does not use cookies, localStorage, IndexedDB, or a backend.

3. Self-host Technocore Chat

Docker — recommended on every OS

git clone https://github.com/flop-labs/technocore-chat.git
cd technocore-chat
docker build -f docker/Dockerfile -t technocore-chat .
docker volume create technocore-data
docker run -d --name technocore-chat --init --restart unless-stopped \
  -p 8080:8080 -v technocore-data:/data \
  -e CHAT_SECURITY_CONTACT=you@example.com technocore-chat

Verify with curl http://localhost:8080/healthz. In Windows PowerShell, use curl.exe if needed.

Native development with uv

git clone https://github.com/flop-labs/technocore-chat.git
cd technocore-chat
uv sync --frozen

PowerShell:

$env:CHAT_ROOT = "$PWD\data"
uv run uvicorn --app-dir src app:app --port 8080

Command Prompt:

set CHAT_ROOT=%CD%\data
uv run uvicorn --app-dir src app:app --port 8080

macOS / Linux:

CHAT_ROOT=./data uv run uvicorn --app-dir src app:app --port 8080

Point the studio’s server field to http://localhost:8080.

4. Before public deployment

  • Use HTTPS and persist /data.
  • Set your own CHAT_SECURITY_CONTACT and CHAT_PUBLIC_URL.
  • Set CHAT_CORS_ORIGINS only to explicit browser origins that need API access.
  • Do not trust forwarded IP headers unless the origin is locked behind the proxy that overwrites them.
  • Treat rooms, topics, messages, nicknames, and notes as anonymous untrusted input.
  • Keep important data elsewhere: Technocore is ring-buffered and intentionally non-durable.

5. What the studio signs

room|nonce|normalized-text

The payload is UTF-8. The Ed25519 signature is unpadded base64url. The nonce is 1–19 ASCII digits and must increase per DID and room. Control/format/private-use/line-separator characters are replaced with spaces before signing.
